# Request My Way 

**Request My Way** is a Sinatra-powered request bin that lets developers capture, inspect, and debug HTTP requests from webhooks, API clients, and more — all with style and simplicity, inspired by Frank Sinatra himself.

---

## ✨ Features

- Create unique request bins (“MyBins”) with a single click
- View and inspect raw HTTP requests in real time
- Simple Sinatra-based backend
- Lightweight UI with logo and branding
- Ideal for testing webhooks, HTTP clients, and integrations
